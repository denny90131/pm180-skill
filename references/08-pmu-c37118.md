# 08 PMU 同步相量 / IEEE C37.118.2 攻略

來源：PM180-Application-Note-PMU、PM180-IEEE-C37-118-2、Operation Manual (PMU 章節、Configuring IEEE C37.118.2)。

## 硬體條件
- PMU 模組 (與 TRM 同一組件)，任一空槽，只能 1 片；**需 N3 版新 CPU (AP1451，內建 IRIG-B)**、韌體 ≥ V31.XX.29；C37.118.2 需 ≥ V31.XX.31 (datasheet 註：最低 N3、v31.x.38)。
- 電壓接 PMU 模組 V1/V2/V3/VN；電流從背板取 AC 輸入。
- **相序必須 ABC** (頻率用正序計算)；若現場 CBA 要在 Basic Setup 改相序，否則量不到頻率。
- 前面板 "PMU OK" LED：黃閃 = 未與 UTC 同步；綠閃 = 已同步。

## 時間同步 (必要)
| 方式 | 接法 | 說明 |
|---|---|---|
| IRIG-B | CPU 模組 1pps/CM 端子 | DCLS 非調變 5V，B000/B001/B004/B005 (含 C37.118.1 Annex D 擴充)，次微秒精度；C37.118.2 Setup 選 IRIG-B |
| IEEE 1588 PTPv2 | PMU 模組的 1588 網口 | **必須經 IEEE 1588-2008 P2P 透明時鐘交換器接 grandmaster**；C37.238 power profile / IEC 61850-9-3：L2 multicast、P2P delay、Announce/Sync 1s、支援 one-step/two-step；PAS → PMU IEEE 1588 Port 設 IP/遮罩/GW 或 DHCP (DHCP 小心 IP 衝突) |
- PTP 狀態檢查：Telnet 連 1588 網口 IP，密碼 `1588`，輸入 `ptp`。

## 量測
- IEEE C37.118.1 P-class / M-class；穩態 TVE < 0.5%。
- 三相電壓/電流同步相量、頻率、ROCOF；正序相量。
- 回報率 (frames/s)：50Hz → 1, 2, 5, 10, 25, 50；60Hz → 1, 2, 3, 4, 5, 6, 10, 12, 15, 20, 30, 60 (設定值會自動進位到額定頻率的約數)。

## IEEE C37.118.2 通訊
- **Commanded (client-server)**：TCP 本地埠 **4712**、UDP 本地埠 **4713**。最多 **5 條**同時串流 (2 種 commanded data stream 可選)；串流資料率需為 PMU 回報率的約數。設定框/標頭框回傳到命令來源，資料框送到發 start 命令的 IP/埠。
- TCP：預設 keepalive，斷線 30 秒關閉；另有閒置逾時 (Network Setup)。
- UDP commanded 無法偵測 client 是否還在 → 異常斷線會佔住串流槽；用 C37.118.2 Setup 的 **Stop UDP Streams = YES** 釋放。Telnet `enet` → `proto` 看目前串流。
- **Spontaneous UDP**：2 個串流可送到兩個不同目的地 (unicast/multicast/broadcast)，需在設定中明確啟用 (預設 Disabled，目的 192.168.0.25 : 4713)。
- 框類型：Data、Configuration (CFG-1/2/3)、Header、Command。可選擴充：類比 (總 P/Q/S/PF) 與數位狀態 (最多 32 DI)。

## PAS 設定 (Communications Setup → IEEE C37.118.2 Setup，連線協定需為 Modbus)

| Configuration Change Count | 0–65535 | 0 |

## 用 Modbus 設定 C37.118.2 (PM180-Modbus「Common Data Exchange」+「IEEE C37.118.2 Setup」)
- 視窗 47480–47603：+0 陣列類型 (**17 = C37.118.2 setup**、23 = channel names)、+1 offset (word)、+2 block length (0–120)、+3 last block、+4~ 資料。先寫類型/offset 再讀寫資料。
- 陣列重點 offset：+0–9 站名、+10 CS stream1 ID、+11 座標格式、+12 資料格式 (0=int16,1=float,2=float 實際頻率)、**+13 PMU reporting rate**、+28 CFG change count、+29/+30 本地 UDP/TCP 埠、+31 Stop UDP、+32 啟用 spont1、+33 spont1 目的埠、+34–35 spont1 目的 IP、+36 P/M class、+37 類比格式、+38 類比 bitmap、+39 DI words、+40 時間源 (0=IRIG-B,1=PTP)、+41 相量類型、+42 spont CFG、**+43 CS stream1 rate**、+44–47 spont2 啟用/埠/IP、+48/+49 spont1 ID/rate、+50/+51 spont2 ID/rate、+52/+53 CS stream2 ID/rate。共 54 words。
- 原文未明說的細節 (寫入是否需一次整塊、IP 的 word 順序)：建議先讀回整塊比對 PAS 設定再寫。

## IEC 61850-90-5 SV
PMU LD 的 MMXU1 (HzRte = ROCOF)、LTIM、LTMS；SV publisher 多播 (見 `07-iec61850.md`)。

## Modbus 讀同步相量
區塊 29824–29903 (Point ID 0x8D00 起)：+0 frame number、+2 UTC 秒、+4 小數秒、+6 時間品質、+8 stream ID、+10 frame status、+12 頻率偏差/實際頻率 (0.001Hz)、+14 ROCOF (0.01Hz/s)、+16~+38 V1–V3/I1–I3 幅值與角度 (0.001°)、+40~+62 各相 Re/Im (**FLOAT32**)、+64~ 正序 V/I。
