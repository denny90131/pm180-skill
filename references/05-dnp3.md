# 05 DNP3 攻略

來源：PM180-DNP (BG0524 DNP3 Reference Guide)。原文：`fulltext/PM180-DNP.txt`。

## 實作重點
- DNP3 **Level 2**，Slave；**不支援 Unsolicited** (必須主站輪詢)、不支援硬體碰撞避免。
- 序列埠設定協定為 DNP3.0 (RDM `Prot = dnP3` 或 PAS Serial Ports)；TCP 埠 20000。
- 設備位址 0–65532 (65533–65535 為廣播，不回應)。
- 支援功能：Read、Write、Direct-Operate、SBO/Operate (SBO 逾時預設 10 秒)、Direct-Operate-No-Ack、Cold Restart、Delay Measurement、檔案傳輸 (波形/事件檔)。
- IIN：0.7 Device restart (寫 0 到 object 80 清除)、0.4 需要校時 (Time Sync Period 預設 86400 秒，設 0 停用)、0.5 Local 狀態、1.5 設定損毀 (清除診斷後消失)。
- 序列埠回應時間：19200bps 約 11ms、115200 約 9ms (含預設 5ms 回應延遲)。

## 縮放 (16-bit 物件)
- 16-bit AI Scaling 預設**啟用**：Var 2/4 (16-bit) 時，雙向量 (功率/PF) 縮放到 −32768~32767，單向量 (V/I/Hz) 縮放到 0~32767。
  `Y = (X − DNP_LO) × (HI − LO) / (DNP_HI − DNP_LO) + LO` (DNP_HI=32767；LO<0 時 DNP_LO=−32768 否則 0)
  例：AI:3 讀 201、CT 200A、Imax=2×200=400A → 201×400/32767 = 2.45A。
- 用 32-bit 物件 (Var 1/3) 不縮放，直接乘單位 (同 Modbus 單位表 U1/U2/U3/U5)。**建議主站讀 Var 1 或 3**。
- 16-bit BC Scaling：×1 (預設)/10/100/1000，讀值要乘回。

## Class 0 與事件
- Class 0 回應內容可自訂 (PAS Protocol Setup → DNP Class 0 Points：選物件/變數、起始點、數量)。
- 事件點總共 **64 個** (AI+BI+BC 合計)，每點指定 Class 1/2/3。條件：Delta (死區)、Over、Under (回差：頻率 0.05Hz、其他 2%)；BI/BC 只能 Delta。
- 掃描：BI 每週波、AI/BC 每 200ms。
- 每種物件/每個 Class 緩衝 512 bytes → 例：32-bit AI 帶時間事件最多 40 筆、BI 帶時間 64 筆。
- 可開啟「事件點重新編號從 0 開始」(AO:74)。
- **改變任何物件事件點數量會清空所有事件緩衝並重設事件點為預設** — 先定好數量再設定。
- 停用事件：把 AI/BI/BC 事件點數都設 0。

## DNP Options 預設 (PAS Protocol Setup → DNP Options)
| 項目 | 預設 |
|---|---|
| BI 事件點數 / AI / BC | (合計 ≤64) |
| BI static 變數 | Single-bit；BI change → With Time |
| AI static | 32-bit −Flag (Var 3)；AI change → 16-bit/32-bit +Time 依設定 |
| BC static | 32-bit +Flag；Frozen BC 32-bit −Flag；BC change 32-bit +Time |
| 16-bit AI scaling | Enabled |
| 16-bit BC scaling | ×1 |
| Re-mapping event points | Disabled |
| SBO Timeout | 10 s (2–30) |
| Time Sync Period | 86400 s |
| Multi Fragment Interval | 50 ms |

## 密碼
密碼保護啟用時，先把密碼寫入 AO:192，否則寫入回 "Control operation not supported"。完成後清除。

## 主站設定建議
1. 鏈結位址 = PM180 埠位址；TCP 20000。
2. 週期 Class 0 (整合) + Class 1/2/3 事件輪詢 (因無 unsolicited)。
3. 依 IIN 0.4 回應校時 (或改用 IRIG-B/SNTP 並把 Time Sync Period 設 0)。
4. 讀 32-bit 變數避免縮放；若主站只吃 16-bit，記得反向換算。
