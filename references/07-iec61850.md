# 07 IEC 61850 攻略

來源：PM180-IEC-61850 (BG0523)、PM180-IEC-61850-PICS (PICS/PIXIT/MICS/TICS)、ICD 範本 (`assets/icd/`，原始在資料夾 `06_IEC61850_ICD/*.zip`)。

## 前提
- 韌體需為 61850 版本：V31.1X.XX (Ed1) 或 V31.2X.XX (Ed2)。訂購碼含 `850`。
- **授權**：出廠為 30 天臨時授權，可再延 1 個月；永久授權需提供設備序號向代理商購買。PAS → Monitor → Administration → Update License → 輸入授權碼 → Send。Modbus 有 "IEC 61850 License Setup" 暫存器 (Grep `IEC 61850 License Setup`)。
- 乙太網路 (CPU ETH 或 TXFX)；Cellular 模組不支援 61850。
- 最多 **4 個 MMS client 同時連線** (PIXIT As1)；MMS PDU 最大 8192；TCP keepalive 1–60s (預設 20s)；client idle timeout 1–10 分 (預設停用)。
- 時間同步 SNTP v3/v4 (Mode 4)；COMTRADE 檔案在 `\COMTRADE\` (不壓縮，可經 MMS 檔案服務讀取)。

## ICD 範本檔
| 版本 | 檔案 | Header |
|---|---|---|
| Edition 1 | `PM180_2003_Rev7.icd` (zip: PM180_IEC61850_ED1-1.zip) | version 31.2003 rev 7 |
| Edition 2 | `PM180_2007B_Rev7.icd` (zip: PM180_IEC61850_ED2.zip) | version 31.2007B rev 7 |
- IED name = TEMPLATE、type PM180、manufacturer "Satec Ltd."
- 預設通訊位址 (ICD)：IP 192.168.0.203 / 255.255.255.0 / GW 192.168.0.1；OSI AP-Title 1,3,9999,106、AE-Qualifier 33、PSEL 00000001、SSEL/TSEL 0001。
- GOOSE：CTRL/LLN0 GoCBPub1，dataset DSetGOOSE1，MAC 01-0C-CD-01-01-FF，APPID 3001，VLAN 0 優先權 4。
- SV (PMU)：PMU/LLN0 MsvCBPub1，dataset DSetSV1，MAC 01-0C-CD-04-01-FF，APPID 4000，smvID `C37.118-StationName-IDCode`。

## 資料模型 (Logical Devices)
| LD | 用途 | 主要 LN |
|---|---|---|
| **MET1** (Measurements) | 量測 | `osvMMXU1` (1 秒/秒級量測：PhV、PPV、A、W、VAr、VA、PF、Hz、Av*、Tot*)、`ocvMMXU1` (1 週波)、`hcvMMXU1`、`phsrMMXU1` (相量)、`demMMXU1-4` (需量)、`maxMMXU1` (最大值)、`engMMTR1` (電能)、`osvMHAI1`/`ocvMHAI1`/`hrmMHAI1`/`demMHAI1` (諧波)、`seqMSQI1`/`hcvMSQI1` (序分量)、`osvMSTA1`/`ocvMSTA1` |
| **CTRL** (Control) | 控制/狀態/錄波 | `QA1/QA2 XCBR1-2` 斷路器、`QB1–QE8 XSWI1-14` 隔離開關、`CSWI1-16` 開關控制器、`CILO1-16` 連鎖、`blkCILO`、`biGGIO1-8` 數位輸入、`boGGIO1-8` 繼電器輸出 (可控)、`evfGGIO1-2` event flags、`spGGIO` setpoint 狀態、`aiGGIO` 類比、`extGGIO1` GOOSE 外部量、`sbsLGOS1-64` GOOSE 訂閱監視、`drRDRE1-8` 擾動錄波 |
| **PMU** (Synchrophasor) | 同步相量 | `MMXU1` (相量、Hz、HzRte=ROCOF)、`LTIM1`、`LTMS1`、`LPHD1` |
- 斷路器/開關前綴 (QA1、QB1…) 可在 Bay Control → Switching Device Setup 改，改後要重新匯出 CID。

## 預設 Dataset / Report
- Dataset (MET1/LLN0)：`DSet01Mx` (平均/總量：AvPhV、AvPPV、AvA、TotW、TotVAr、TotVA、TotPF、Hz)、`DSet02Mx` (各相 PhV、PPV、A 含 neut)、`DSet03Mx` (各相 W/VAr/VA…)、`DSet04St`、`DSet05Mx`；狀態 `DSet01StInd`…`DSet09StInd`、`DSet04StSPCSO`…`DSet07StSPCSO`、`DSet09StFltNum`。
- GOOSE dataset：`CTRL/LLN0$DSetGOOSE1`；SV dataset：`PMU/LLN0$DSetSV1`。
- RCB：CTRL 與 MET1 各 8 個 URCB (`URep01–08`) + 8 個 BRCB (`BRep01–08`)。可設 "Number of RCB instances" 給多 client (先設實例數再設 RCB)。BRCB 緩衝 64KB。
- 所有 RCB 屬性可在 RptEna=FALSE 時線上修改；啟用中不可改。

## 量測單位與死區
- 電流 A/kA (0.01A)；電壓 V/kV (PT=1 時 0.1V、PT>1 時 1V)；功率 kW/MW 等 (PT=1 0.001kW、PT>1 1kW)；能量 0.001–1 kWh。
- 量測上下限 (死區百分比的基準)：電流 0–Current scale×CT 比、電壓 0–Voltage scale×PT 比、功率 ±Vmax×Imax×2/1000…
- db = (max−min) 的百分比；預設死區：相電壓/電流 1.000%、擴展電流 0.133%、不平衡 0.333%… PAS → IEC 61850 Setup → Report Deadbands 可一次改同類全部 (0.001–50%)，再於 client 端個別微調。
- **先設好 PT/CT/scale 再設死區**。

## 控制
- LLN0.Mod 永遠 ON。
- **Loc = NOT(REMOTE MODE)**；REMOTE MODE (REMOTE CONTROL 旗標) 預設 FALSE → 必須用 setpoint 邏輯 (通常讀 Local/Remote 切換開關 DI) 執行 "REMOTE CONTROL" 動作設為 TRUE，否則 CSWI / boGGIO 命令被拒 `AddCause=2 Blocked-by-switching-hierarchy`。
- 可依 client IP 限制控制權 (Bay Control → Control Ports)。
- 開關控制模型：direct-with-enhanced-security，CommandTermination 回報 (詳見 `09-bay-controller.md`)。

## GOOSE
- Publisher：PAS → IEC 61850 Setup → GOOSE Publisher Setup：目的 MAC、GOOSE ID、APPID、最大重傳間隔、confRev；Publisher Enabled = Yes。Ed2 可選 dataset (同 LD)。
- Subscriber：最多 20 個訂閱 (Ed2 ICD 有 sbsLGOS1–64)，每個最多 16 個元素；從發布端 CID/IID/SCD 匯入 ("Open SCL File" → 勾 dataset → 勾元素)。
  - 對應內部變數：`ExtInd1–128` (BOOLEAN/Dbpos/整數最低位)、`ExtiVal1–32` (INT32)、`ExtfVal1–32` (FLOAT32)。
  - 無更新/逾時/dataset 不符 → 變數歸零、訂閱狀態非作用 (CTRL/sbsLGOSn 或 Modbus 44338/44340)。
  - 支援帶/不帶 VLAN tag。
  - dataset 成員參照只存在 IED database，不會下載到設備 — 要記得 Save。
- 用途：跨設備連鎖 (遠端開關位置進 ExtInd 給 CILO 邏輯)。

## Sampled Values (PMU 同步相量 IEC 61850-90-5)
- PAS → SV Publisher Setup：多播 MAC 01:0C:CD:04:00:00–01:0C:CD:04:01:FF、APPID、smvID (`C37.118-<Station>-<IDCode>`)、VLAN、可選欄位、取樣率 (frames/s，會自動調成額定頻率的約數)、SV Transmission Enabled = Yes。
- 詳見 `08-pmu-c37118.md`。

## 標準工作流程 (PAS IEC 61850 Setup)
1. 建 site、上線確認韌體為 61850 版、授權有效。
2. **IED Configurator** 頁 → Initialize (預設) / Import from… (其他 IED DB) / Save from IED (從設備上傳)。
3. **IED Properties**：Edition、IED name (會串接在 LD 名前)、位置 (亦用作 COMTRADE station_name)、RCB 實例數、keepalive、idle timeout → Save as → Send。
4. **Datasets**：新增/修改需用 CID/IID 檔 ("Edit from file")。先建 dataset 再設 Report。
5. **Reports**：Report ID、Dataset、confRev、Optional fields、Trigger options、Buffer time、Integrity period。
6. GOOSE Publisher / Subscriber、SV Publisher、Report Deadbands。
7. **Export SCL file**：以 ICD 範本 (Ed1: PM180_2003_RevXX.icd、Ed2: PM180_2007B_RevXX.icd) 為來源，輸出 CID/IID/ICD (輸出 .icd 時 IED name 寫成 TEMPLATE)。改 IED name 或開關前綴後要重新匯出。
8. 系統整合商：可用 **Import SCD file** 從 SCD 匯入 IED name、網路參數、GOOSE/SV 通訊設定。
9. **Download to IED** (On-line)。**注意：下載 61850 設定不會改 IP**，IP 要在 Communication Setup → Network Setup 另外改。
10. 重置：Monitor → Administration → Master Reset → Reset IEC 61850 Configuration (網路會重啟)。
