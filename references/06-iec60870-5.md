# 06 IEC 60870-5-101 / 104 攻略

來源：PM180-IEC-60870-5 (BG0591)、Operation Manual Ch9。原文：`fulltext/PM180-IEC-60870-5.txt`。

## 連線
- **101**：序列埠 (非平衡 unbalanced)，協定選 IEC 60870-5 (Modbus 設定暫存器值 7)。
- **104**：乙太網路 TCP **2404**，可多連線 (與 Modbus 502、DNP 20000 同時使用不互相影響 → 可同時用 PAS 監看)。
- 104 閒置 **2 分鐘**無活動即關閉連線 → 主站送 TESTFR，或啟用 cyclic 傳送維持活動。
- 未確認 ASDU 數超過上限 (預設 12，k 值) 會暫停傳送；設 0 = 不暫停。
- **只有一個主站能收到 spontaneous 事件** (單一事件緩衝)；設了 104 spontaneous client IP 就不要再從序列埠送 class 1 請求。

## 位址
- 101：鏈結位址、ASDU 共同位址 (CASDU)、COT、IOA 長度皆可設 (1–2 / 1–2 / 1–2 / 1–3 octets)。選 1 octet IOA 只能用 1–255 的 mapped 點，且無法經 101 設定設備。
- 104：固定 CASDU 2 octets、COT 2 octets、IOA 3 octets、最大框長 253。
- CASDU = 該通訊埠的設備位址 (1–254 或 1–65532)。

## 資訊物件位址 (IOA)
- **一般物件 IOA = Point ID + 16384** (與 Modbus 文件中的 Point ID 相同)：
  - 1 秒相值 0x1100 → IOA 20736 起 (V1=20736、V2=20737、V3=20738、I1=20739…順序同 Modbus 表，每點 1 個 IOA)
  - 1 秒總值 0x1400 → 21504 (Total kW)、21505 kvar、21506 kVA、21507 PF…
  - 1 秒輔助 0x1500 → 21760 (I4)、21761 In、21762 頻率…
  - 能量 0x1700 → 22272 (kWh import)、22273 kWh export… (M_IT)
  - 計數器 0x0A00 → 18944 (Counter #1)
  - DI 0x0600 → 17920 (DI1) … (M_SP)；繼電器 0x0800 → 18432 (RO1) (M_SP + C_SC 單點命令)
  - 內部靜態事件 0x0900 → 18688–18697；Setpoint SP1–64 → 48128–48191
  - 雙點：DI 對 64512 起、繼電器對 64640 起 (M_DP + C_DC)，存取時用一對中的第一個位址
- **Mapped points 1–4095**：最多 64 個一般點重新對應到使用者位址；**事件回報只對 mapped 點有效**。
  - 預設起始：量測值 1、單點 101、雙點 201、累計量 301 (依序排列：量測→單點→雙點→累計)。
  - PAS：IEC 60870-5 Setup → Mapped Points and Events Setup，選群組/參數、門檻 (Delta / Over / Under；回差頻率 0.05Hz、其他 2%)、勾 Class 1。

## 資料型別與換算
| 型別 | 說明 | 換算 |
|---|---|---|
| M_ME_NA/TA/TD (Normalized) | 16-bit F16 | `Y = raw × Max_Range` (raw 視為 /32767) |
| M_ME_NB/TB/TE (Scaled, **預設**) | 16-bit 整數 | `Y = raw × Scale_Factor`；若 Max/Resolution ≤32767 → SF=Resolution，否則 SF=Max/32767 |
| M_ME_NC/TC/TF (Float) | IEEE R32 | 直接是真值 (**SCADA 最省事，建議用**) |
| M_IT (累計量) | 32-bit | 能量依 U5 單位 |
- 例 (原文 §2.13.4)：I1 電流、CT 200A → Max=400A、Res 0.01A → 400/0.01=40000>32767 → SF=400/32767，raw 201 → 2.45A。
  (原文範例寫「IOA 20736 代表 I1」，但依點表 20736 是 V1、I1 是 20739 — 以點表為準。)
- **注意 IOA 重疊**：同一個 IOA 數字可能在不同型別各代表不同點 (例 17920 = 單點 DI1，也是量測值 Programmable Min/Max 區；18944 = 累計量 Counter #1，也是量測值 Min/Max Maximum 區)，主站要依 ASDU 型別區分。
- 超量程：OV bit 置 1。
- 量測單位可選：電壓 V/kV、電流 A/kA、功率 kW/MW (IEC 60870-5 Options)。

## Interrogation / Cyclic / 計量
- General & Group interrogation (最多 15 組)，範圍在 **Class 2 Data and Counters Setup** 設定 (最多 32 範圍，連續填寫不可空行)。
- Cyclic：104 依 cyclic period (100–30000ms，0=關) 傳給 "Client IP for cyclic transmission"；101 以 class 2 回應。
- 累計量模式 A/B/C/D：local freeze 週期 (1–60 分，整除 1 小時則對齊整點)、freeze with reset、counter interrogation FRZ 0–3。多主站時只能有一個用 FRZ 1–3。
- 事件掃描：二元每週波、類比 200ms；緩衝 128 筆。
- 時鐘：設備時間為**本地時間**；IV 位元在失電後為 1，C_CS_NA_1 校時後清除；104 避免 CP24Time2a 時標。

## 命令 (繼電器)
| SCS | QU | 動作 |
|---|---|---|
| 1 (OFF) / 2 (ON) | 0 或 1 | 短脈衝 ON (預設 500ms) |
| 1 / 2 | 2 | 長脈衝 ON (預設 1000ms) |
| 1 | 3 持續 | Latched OFF |
| 2 | 3 持續 | Latched ON |
- SBO 逾時預設 10 秒；雙點命令送到一對位址的第一個。

## IEC 60870-5 Options 預設 (PAS → IEC 60870-5 Setup)
最大框長 255、鏈結位址 1 octet、COT 1 octet、CASDU 1 octet (101)、IOA 2 octets (101)、SBO 10s、短脈衝 500ms、長脈衝 1000ms、Time sync period 0、Local freeze 0、k=12、Cyclic 0、Client IP 0.0.0.0、量測預設型別 M_ME_NB_1 (事件 M_ME_TE_1)、單點 M_SP_NA_1 (事件 M_SP_TB_1)、雙點 M_DP_NA_1 (事件 M_DP_TB_1)、累計 M_IT_NA_1 (事件 M_IT_TB_1)。
- **注意**：104 的 spontaneous / cyclic 都需要填 Client IP，否則不會主動送。

## 建置步驟
1. 決定 101 或 104、CASDU、IOA 規劃 (要事件就一定用 mapped 1–4095)。
2. PAS → IEC 60870-5 Options (型別建議改 Float M_ME_NC_1 / 事件 M_ME_TF_1)、Client IP。
3. Mapped Points：挑最多 64 點，設死區與 Class 1。
4. Class 2 Data and Counters：設定 general interrogation 範圍、cyclic、累計量 freeze。
5. Save → Send；主站做 GI 驗證。
